# LiveFace Studio — Free Starter

A mobile-friendly static camera-effects demo for free GitHub Pages hosting.

## Features
- Front/back camera selection where supported
- Selfie mirror preview
- Browser-based visual filters
- Snapshot download
- Responsive mobile layout

## Publish with GitHub Pages
Upload `index.html` and `README.md` to the root of your repository. Go to Settings → Pages → Build and deployment → Deploy from a branch, choose `main` and `/(root)`, then Save. Open your published HTTPS address once deployment completes.

## Important limitation
This starter does not include AI face identity replacement or a virtual camera for other apps. Those require an AI model and additional processing. Camera access needs HTTPS. Use another person's likeness only with their permission.
